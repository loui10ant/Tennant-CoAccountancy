# 1. Project Vision

## Purpose

The Tennant & Co Accountancy website is the primary online presence for the business.

The objective is to create a modern, premium and trustworthy website that clearly communicates the services offered, builds confidence with prospective clients and generates new business enquiries.

The website will be engineered as a software project using modern development practices rather than a traditional drag-and-drop website builder.

---

# 2. Project Goals

The website should:

- Present Tennant & Co as a premium accountancy practice.
- Generate qualified enquiries.
- Clearly explain services and pricing.
- Inspire trust.
- Be easy to maintain.
- Load extremely quickly.
- Be fully responsive.
- Be accessible to all users.
- Be optimised for search engines.
- Provide a platform for future expansion.

---

# 3. Engineering Principles

The project will follow these principles:

1. Clarity over cleverness.
2. Performance is a feature.
3. Accessibility is mandatory.
4. Mobile-first development.
5. Consistency throughout the codebase.
6. Documentation evolves with the software.
7. Build only what is required for the current sprint.
8. Every commit should leave the project in a better state.
